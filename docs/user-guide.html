01

Browse the storefront

The home page opens on Special Offers. Use the category bar to browse, then choose a product to see its details.

Steps

  1. Use the category bar to browse departments. On smaller screens, use the ‹ and › arrows to move through the menu.
  2. Select a product card to open the product page. The product category and subcategory appear above its name.
  3. Use the cart icon in the header to review items at any time.

Customer workflow · checkout

04

Review and place an order

Checkout saves the order and opens WhatsApp with the order details ready to send.

Steps

  1. Use +/− to adjust quantity or Remove to take an item out of the cart.
  2. Enter your name and phone number. Customer numbers may use +947xxxxxxxx or 07xxxxxxxx.
  3. Choose Checkout via WhatsApp. The order is saved first, then WhatsApp opens with the order reference and item list.

Admin tools · order management

09

Track and update orders

Orders are grouped by status so the team can review each stage of fulfillment.

Illustrative admin data

Steps

  1. Use Orders, Shipped, Returned, and Refund tabs to switch between statuses.
  2. Select + to inspect order line items; − closes the expanded details.
  3. Pending orders can be edited, deleted, or marked shipped. Shipped orders support delivery tracking; returned orders support receipt, reshipment, or refund actions.
  4. Confirm status-changing actions carefully; some actions cannot be undone.

10

Edit order details

The order editor lets an admin correct customer details and line items before saving.

Illustrative admin data

Steps

  2. Adjust item quantities/prices or remove a line item. The total is recalculated from the items.
  3. Choose Save Changes to apply the update, or Cancel to close without saving.
